# Selfmade Approach

This directory contains our implementation of the *selfmade* approach from Rügamer et al. (2022) for **valid post-selection inference in linear mixed models**.

## Main File

```
selfmade**
```

## Usage

```bash
R selfmade**
```

## Description

The script performs valid inference for linear mixed models after data-driven model selection.
See the paper for details.
